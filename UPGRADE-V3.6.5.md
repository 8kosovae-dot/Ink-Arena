# Ink Arena v3.6.5 — Private Room UI polish

This is a styling-only update to v3.6.4.

- The Create private room button expands vertically to use the open space in its panel.
- The Join private room button is larger to keep the two actions visually balanced.
- Private-room headings, labels, descriptions, and helper text are larger and easier to read.
- Responsive layouts retain stacked panels and appropriately sized buttons on smaller screens.

No database migration or JavaScript changes are required. Keep your existing `config.js` when updating an existing deployment.

## Apply the patch

Replace the existing `style.css` with the `style.css` included in this update. No other website files need to change.
